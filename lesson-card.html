# [Your Name]'s Teaching Programming Portfolio A web-based portfolio showcasing my work teaching programming — lessons, videos, docs/slides, and Scratch/Snap! projects, all in one public log. 🔗 **Live site:** https://[username].github.io/ ## Structure ``` _lessons/ one file per lesson (shows up on the home page, newest first) _layouts/ page templates (default.html, lesson.html) _includes/ reusable pieces (header, footer, lesson card) assets/css/ styling index.md home page (lists all lessons) about.md about page ``` ## Adding a new lesson 1. Copy a file from `_lessons/`, name it `YYYY-MM-DD-short-title.md`. 2. Edit the front matter at the top: ```yaml --- title: "Lesson title" date: 2026-03-01 video: "https://..." # optional doc: "https://..." # optional — Google Doc/Slides/Jamboard project: "https://..." # optional — Scratch/Snap! project --- ``` 3. Write a short description below the `---`. 4. Commit and push to `main` — GitHub Pages rebuilds automatically. ## Running locally ```bash bundle install bundle exec jekyll serve ``` Then visit `http://localhost:4000`. ## Enabling GitHub Pages Settings → Pages → set **Source** to the `main` branch (root). The site publishes at `https://[username].github.io/` (or `https://[username].github.io/[repo-name]/` for a project repo — update `url`/`baseurl` in `_config.yml` to match).
